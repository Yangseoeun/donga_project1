# pages 폴더

Streamlit 멀티 페이지 화면을 관리하는 폴더입니다. 파일명 앞 숫자는 페이지 표시 순서를 의미합니다.

## 파일 설명

| 파일 | 설명 | 담당 |
| --- | --- | --- |
| `1_일반_사주.py` | 생년월일시 입력 폼, 사주 계산 요청, 일반 리포트 화면을 담당합니다. | Streamlit 프론트, 백엔드 A 연동 |
| `2_채팅_사주.py` | 사주 컨텍스트 기반 AI 채팅 화면을 담당합니다. 상담 모드, 스트리밍 옵션, 채팅 기록을 관리합니다. | Streamlit 프론트, 백엔드 B 연동 |

## 연결 흐름

- `1_일반_사주.py`에서 `calculate_saju()`를 호출합니다.
- 계산 결과는 `st.session_state["user_saju"]`에 저장됩니다.
- `2_채팅_사주.py`는 같은 `user_saju`를 읽어서 LLM 프롬프트에 사용합니다.

## 수정 규칙

- 화면 배치나 입력 폼은 이 폴더에서 수정합니다.
- 반복되는 HTML/CSS UI는 `ui/components.py`와 `ui/styles.py`로 옮기는 것을 권장합니다.
- OpenAI API 직접 호출은 금지하고 `core/chat_engine.py`를 사용합니다.
