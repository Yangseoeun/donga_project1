# utils 폴더

여러 화면과 모듈에서 함께 쓰는 보조 기능을 모아둔 폴더입니다.

## 파일 설명

| 파일 | 설명 | 담당 |
| --- | --- | --- |
| `__init__.py` | `utils`를 Python 패키지로 인식시키는 파일입니다. | 공통 |
| `helpers.py` | Streamlit 세션 상태 초기화, 데모 사주 데이터 생성 함수를 제공합니다. | 프론트, 공통 |
| `logger.py` | 공통 로거 생성 함수를 제공합니다. | 공통 |

## 수정 규칙

- 세션 상태 기본값은 `helpers.py`의 `init_session_state()`에서 관리합니다.
- 개인정보는 로그에 남기지 않습니다.
- 여러 파일에서 함께 쓰는 작은 함수만 이 폴더에 둡니다.
