# docs 폴더

기획, 설계, API 명세, 프롬프트 설계, 발표 자료에 참고할 문서를 관리합니다.

## 파일 설명

| 파일 | 설명 | 담당 |
| --- | --- | --- |
| `architecture.md` | 전체 구조와 역할별 소유 파일을 설명합니다. | 공통, 발표 |
| `api_spec.md` | 백엔드 B가 프론트에 제공하는 채팅 함수 인터페이스를 설명합니다. | 백엔드 B |
| `prompt_design.md` | 상담 모드별 프롬프트 설계 방향을 정리합니다. | 백엔드 B, 기획 |
| `requirements.md` | 서비스 요구사항을 정리할 예정인 문서입니다. | 기획 |

## 수정 규칙

- 코드와 문서 내용이 달라지면 문서도 함께 수정합니다.
- 발표/PPT 담당자는 이 폴더 문서를 참고해 서비스 구조를 정리하면 됩니다.
